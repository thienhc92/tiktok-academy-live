# Temple presentation assets

`shrine-realistic.webp`, `devotee-realistic.webp` and `devotee-standing.webp` were
newly generated for this prototype on 2026-11-05, then encoded/resized for the web.
They are recreations, not the original screenshot's background or character models.
The original generated PNGs are preserved outside this repository in the execution
workspace. Only optimized copies are shipped. `altar.svg` remains from the initial
prototype but is not used by the revised default experience.

`fonts/Charm-Bold.ttf` comes from Google Fonts, Charm by The Charm Project Authors
(Cadson Demak). Source: https://github.com/google/fonts/tree/main/ofl/charm .
The accompanying `fonts/OFL.txt` carries the SIL Open Font License. This is a visual
approximation of the reference calligraphy, not a claim to use its original font.
